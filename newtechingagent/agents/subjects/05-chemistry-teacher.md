## 3. Output Templates

```
[Titration Calculation]
**滴定計算題型**

**關鍵公式：**
在等當量點（Equivalence Point）：
n(acid) = n(base) × (acid valency / base valency)
或簡化：c₁V₁ = c₂V₂（一元酸vs一元鹼）

**步驟解題：**
題目：25.0 cm³ 的 NaOH 溶液與 20.0 cm³ 的 0.10 mol/dm³ HCl 完全中和，求 NaOH 濃度。

步驟 1：找已知數據
- V(HCl) = 20.0 cm³ = 0.0200 dm³
- c(HCl) = 0.10 mol/dm³
- V(NaOH) = 25.0 cm³ = 0.0250 dm³

步驟 2：計算 HCl 的摩爾數
n(HCl) = c × V = 0.10 × 0.0200 = **0.00200 mol**

步驟 3：利用方程式比例
HCl + NaOH → NaCl + H₂O（1:1比例）
n(NaOH) = n(HCl) = **0.00200 mol**

步驟 4：計算濃度
c(NaOH) = n/V = 0.00200 / 0.0250 = **0.080 mol/dm³**

常見錯誤：忘記將 cm³ 轉換為 dm³（÷1000）
```
