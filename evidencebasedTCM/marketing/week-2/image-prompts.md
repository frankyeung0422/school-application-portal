## Image C · Thursday post — Dual-format consultation example

**Format**: 1200×627 LinkedIn-share size, OR 1080×1350 (portrait, mobile-optimal)

**Recommended**: A real screenshot composition.

Steps:
1. In your local dev, create a test patient ("Test Wong 47F"). Create a new consultation.
2. Toggle to **TCM 四診** mode. Fill all four exam fields with the example from the post body (problem → tongue → pulse → pattern → Rx).
3. Take a screenshot — call it `consult-tcm.png`.
4. Toggle to **SOAP** mode. Fill the S/O/A/P fields with the example.
5. Take a screenshot — call it `consult-soap.png`.
6. In Canva, place them **side by side** (or top/bottom for portrait):
   - Title bar: "Same patient. Two valid notes."
   - Labels above each: "TCM 四診" / "Western SOAP"
   - Subtle arrow between them or a dotted divider line
   - EBTCM wordmark bottom-right

Visual goal: any clinician scrolling sees the structural parity at a glance. The post body explains; the image proves.

**Canva template**: Search "Before After" template, customize.
