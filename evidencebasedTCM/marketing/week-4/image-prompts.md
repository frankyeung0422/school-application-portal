# Week 4 — Image specs

## Image F · Monday post — 30-day metrics dashboard

**Format**: 1200×627

**Recommended (real)**: a screenshot of an actual numbers dashboard.

Build a tiny page at `/admin/30-day-dashboard` (or just a Notion/Coda page) showing:

```
30 DAYS OF EBTCM · Day 1 → Day 30

   Paying customers      0 → [N]      ▲
   Demos done            0 → [N]      ▲
   LinkedIn followers    [X] → [Y]    ▲
   Email subscribers     0 → [N]      ▲
   Public checker users  — → [N]      ▲
   Database entries      207 → [N]    ▲

The honest score after 30 days of build-in-public.
EvidenceBasedTCM.com
```

Use a clean monospace font (JetBrains Mono / IBM Plex Mono). Numbers should feel like a CLI output — that's the build-in-public aesthetic.

If you can't build a real dashboard, mock it up in Canva using the same layout.

**Don't**:
- Use celebratory emoji 🎉 — undercuts the honesty.
- Hide the lower numbers below the fold. The whole point is they're all visible.
- Add a logo bigger than the numbers. The numbers are the brand.

## Image G · Thursday post — Evidence data viz

**Format**: 1080×1350 (portrait) — works for both LinkedIn and Substack

**Concept**: A horizontal stacked-bar chart showing evidence distribution across major TCM intervention categories. Show the conditional truth: "TCM has Grade A evidence, just not evenly."

**Build in Canva or any chart tool**:

Categories (Y-axis, top to bottom — order by Grade A density):
- Acupuncture (migraine, low-back pain) ← high Grade A
- COVID-19 (連花清瘟) ← high Grade A
- Post-stroke recovery (補陽還五湯) ← high Grade A
- Glycemic control (黃連) ← Grade B-A
- Insomnia (酸棗仁湯) ← Grade B
- Depression adjunct (逍遙散) ← Grade B
- Functional dyspepsia (六君子湯) ← Grade B
- Cancer adjunct ← Grade B-C
- Pediatric conditions ← Grade C-D (the gap)

For each row: a stacked horizontal bar showing % Grade A / B / C / D.

**Color**: emerald `#10b981` for A, lime `#65a30d` for B, amber `#f59e0b` for C, slate `#64748b` for D.

**Title at top**: "TCM evidence is uneven — by intervention category"
**Subtitle**: "n = 707 entries, EBTCM database, 2026.05"
**Annotation arrow** at the bottom row: "← The biggest evidence gap"
**Footer**: "evidencebasedtcm.com/evidence"

This chart works as a standalone screenshot people will save and reference. Take time to make it look right.

## Substack Newsletter #2 — Header image

**Format**: 1456×816

**Concept**: Same visual style as Newsletter #1 for brand continuity, but evolved.

- Top-down photo: open notebook with handwritten retrospective notes (real or staged), a laptop showing a chart on screen (the bar chart from Image G), a small jar of 黨參 or 紅棗, a coffee mug. Late-afternoon natural light.
- OR if illustration: same Midjourney style as #1, but add a small detail like a "30 / 30" checkbox or a "day 30" date stamp visible on the notebook.

**Key**: keep the palette identical to Newsletter #1 so subscribers' eyes recognize the brand. The hero image should feel like a familiar series, not a new aesthetic each time.

## Production tip — by Week 4 you should have ~6 reusable image templates

Going forward (Week 5+), you should not be building new images from scratch each week. Templates you've now built:

1. ✓ LinkedIn share-card (origin / build-in-public)
2. ✓ Carousel slide template
3. ✓ Dual-format consultation comparison
4. ✓ Evidence pyramid
5. ✓ 30-day dashboard
6. ✓ Evidence distribution bar chart

Save each as a master Canva file. Future posts duplicate, swap text/numbers, re-export. Aim for 30-min production time per post by Week 6.
