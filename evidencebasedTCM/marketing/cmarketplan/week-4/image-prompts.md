# 第 4 週 — 圖片規格

## Image F · 週一貼文 — 30 日指標儀表板

**格式**：1200×627

**建議（真實）**：實際數字儀表板截圖。

建一個小頁面在 `/admin/30-day-dashboard`（或只是 Notion / Coda 頁面）顯示：

```
EBTCM 的 30 日 · 第 1 日 → 第 30 日

   付費客戶              0 → [N]      ▲
   完成示範              0 → [N]      ▲
   LinkedIn 追蹤者       [X] → [Y]    ▲
   電郵訂閱者            0 → [N]      ▲
   公開查詢工具訪客      — → [N]      ▲
   資料庫條目            207 → [N]    ▲

30 日公開建造的誠實成績單。
EvidenceBasedTCM.com
```

用乾淨的等寬字型（JetBrains Mono / IBM Plex Mono）。數字應有 CLI 輸出感 — 那是公開建造美學。

如果做不出真實儀表板，在 Canva 用同樣排版製作 mockup。

**不要**：
- 用慶祝 emoji 🎉 — 破壞誠實感。
- 把較低數字藏在折疊下方。整個重點是它們都可見。
- logo 比數字大。**數字才是品牌。**

## Image G · 週四貼文 — 證據資料視覺化

**格式**：1080×1350（直幅） — LinkedIn 與 Substack 都適用

**概念**：水平堆疊長條圖，展示主要中醫療法類別的證據分佈。展示有條件的真相：「中醫有 A 級證據，只是分佈不均。」

**在 Canva 或任何圖表工具製作**：

類別（Y 軸，由上至下，依 A 級密度排序）：
- 針灸（偏頭痛、下背痛） ← 高 A 級
- COVID-19（連花清瘟） ← 高 A 級
- 中風後復康（補陽還五湯） ← 高 A 級
- 血糖控制（黃連） ← B-A 級
- 失眠（酸棗仁湯） ← B 級
- 憂鬱症輔助（逍遙散） ← B 級
- 功能性消化不良（六君子湯） ← B 級
- 癌症輔助 ← B-C 級
- 兒科疾病 ← C-D 級（缺口）

每一列：水平堆疊長條，顯示 A/B/C/D 級的百分比。

**色彩**：A 級翠綠 `#10b981`、B 級石灰綠 `#65a30d`、C 級琥珀 `#f59e0b`、D 級石板 `#64748b`。

**頂部標題**：「中醫證據分佈不均 — 按療法類別」
**副題**：「n = 707 條，EBTCM 資料庫，2026.05」
**底部一列加註箭頭**：「← 最大證據缺口」
**頁尾**：「evidencebasedtcm.com/evidence」

這張圖可作為獨立截圖被收藏與引用。花時間做好。

## Substack 電子報 #2 — 主視覺

**格式**：1456×816

**概念**：與電子報 #1 同樣視覺風格，但有進展。

- 俯視照：打開的筆記本附手寫回顧筆記（真實或擺拍）、一台筆電顯示圖表（Image G 的長條圖）、一小罐黨參或紅棗、一杯咖啡。下午自然光。
- 或若用插畫：與 #1 同 Midjourney 風格，但加小細節，如「30 / 30」打勾框或筆記本上可見的「day 30」日期戳。

**重點**：色調與電子報 #1 完全相同，讓訂閱者眼睛認出品牌。主視覺應該感覺像熟悉的系列，不是每期換新美學。
