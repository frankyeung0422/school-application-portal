# Facebook 排程指南 · FB Business Suite

**目標**：本週末用 60 分鐘把 24 篇貼文全部排程，接下來 30 天 FB 自動發布。

---

## 預備

### 你需要：
- 一台桌機（手機版 FB Business Suite 排程功能受限）
- Chrome / Edge / Firefox
- 24 張 PNG 海報（從 SVG 模板匯出）
- 24 篇貼文文字（已在 `week-1..4/` 各檔案中）

### 一次性設定（5 分鐘）：

1. 開 https://business.facebook.com
2. 用個人 FB 帳號登入
3. 若還沒建立「業務管理平台」 → 點「建立帳戶」→ 名稱填 `EBTCM` → 完成
4. 在「資產」→「Pages」→ 新增 EBTCM 專頁（已建立的話直接連結）
5. 確認左側選單看到 **「Planner」（排程工具）** — 這就是要用的工具

---

## 步驟 1：批次匯出 24 張海報 PNG（20 分鐘）

每個 SVG 模板有 6 種用法 — 你需要先改文字、匯出 PNG。

### 方法 A：用 VS Code + 瀏覽器（推薦）

1. 在 VS Code 開 `marketing/cmarketplan/facebook-posts/poster-templates/01-hook-photo.svg`
2. 找到 `<!-- EDIT: ... -->` 註解 → 換成本週貼文需要的文字（見每篇 `.md` 的「海報文字」段落）
3. 另存為新檔案，例如 `rendered/week-1/01-mon-origin.svg`
4. 用 Chrome 開 SVG 檔案 → 右鍵 → 「將圖像另存為...」 → 取消勾選縮放 → 選 PNG
5. 重複 24 次

### 方法 B：等待自動腳本（明天可用）

我正在建 `npx tsx scripts/render-svg-to-png.ts` — 一次匯出所有 PNG。建好後告訴你。

### 方法 C：用 Canva 重做（給不愛改 SVG 的人）

1. Canva → 「Custom size 1080×1080」
2. 把 SVG 拖入 → 改文字 → 匯出 PNG
3. 比改 SVG 慢但介面更直覺

---

## 步驟 2：打開 FB Business Suite Planner（5 分鐘）

1. https://business.facebook.com → 左側 **「Planner」**
2. 確認頂部選的是 **實證中醫 EBTCM 專頁**（不是個人檔案）
3. 切換到 **「Calendar」** 模式 — 看到 30 日月曆檢視

---

## 步驟 3：批次新增 24 篇貼文（30 分鐘）

對每篇 `.md` 檔案：

1. 在 Planner 點擊目標日期 → 「Create post」
2. **媒體**：上傳對應 PNG 海報
3. **貼文文字**：從 `.md` 檔案複製「貼文內文」整段（包括 emoji 與 hashtags）
4. **發布時間**：依 README 的「最佳發文時段」設定 — 通常是：
   - 週一/三/五：上午 09:00 或晚上 20:00 HKT
   - 週二/四：上午 08:00 或晚上 19:30 HKT
   - 週六：上午 10:00 HKT
5. **第一則留言**（FB 支援！）：捲到下方「留言」區，預設第一則為你 — 貼上連結（CTA URL）
6. 點 **「Schedule」**

重複 24 次。

### 加速技巧：

- **批次預覽**：先按上面的方式新增 24 篇 draft，最後一次性點 Schedule
- **複製貼上模板**：6 個海報範本可以重複用，週四「名醫」系列尤其重複度高
- **Hashtag 預設庫**：在 Planner 設定中建立 "Hashtag groups"，發文時一鍵插入

---

## 步驟 4：檢視排程行事曆（5 分鐘）

排完後切到 **「Calendar」** 看月曆：

✅ 每天有貼文嗎？
✅ 沒有相同主題連續兩天？
✅ 週五的警示貼文有沒有被晚上時段擠掉？
✅ 標籤的位置看起來自然嗎？

調整任何不對勁的，按 "Reschedule"。

---

## 步驟 5：監測（每日 10 分鐘）

接下來 30 天，每天早上花 10 分鐘：

1. 開 **Business Suite → Insights** → 看昨日貼文成效
2. 觸及率最高的 → 加 Boost（HK$100-200）
3. 觸及率低的 → 不用管，下個月別重複該風格
4. 留言區回覆 → 用手機 FB App 或桌機都可以，目標 **2 小時內回覆**

---

## 排程心法

✅ **批次處理**：別每天現場貼文。週日下午一次排好整週。
✅ **保留 20% 即興空間**：突發新聞（如政策變動、明星推薦中醫）可以插入。
✅ **第一週後檢視**：哪 2 篇表現最好？把模板複製到第 2 個月。
❌ **別過度修改**：排程後 24 小時內別改文字，演算法會 reset 觸及。
❌ **別在週日早上發**：HK 用戶週日活躍度最低（教堂、家庭時段）。

---

## 故障排除

| 問題 | 解法 |
|------|------|
| 排程按鈕灰色 | 確認時間至少 10 分鐘後 |
| 圖片上傳失敗 | PNG < 4 MB；先在 https://tinypng.com 壓縮 |
| 多人共用專頁 | 業務管理平台 → 人員 → 加管理員 |
| 想取消已排程貼文 | Planner → 點該貼文 → 「Delete draft」 |
| 中文字型顯示異常 | 上傳前在 SVG 中改成內嵌字型，或用 Canva 重做 |

## 30 天後

當你看到效果（哪些 work、哪些不 work），自動化方案就上線：

- FB Graph API 整合

但**先用手動排程一個月**，確認內容方向後，自動化才有價值。
