# Facebook 貼文系統 · 實證中醫 EBTCM

24 篇 FB 貼文 + 6 個可重用 SVG 海報模板，配合 30 天行銷計劃執行。

## FB vs. LinkedIn 的關鍵差異

| 維度 | LinkedIn | Facebook |
|------|----------|---------|
| 受眾 | 醫師專業圈 | 病人 + 醫師 + 大眾 |
| 長度 | 200-300 字 | **50-150 字**（短！） |
| 語氣 | 專業、嚴肅 | 親切、情感化 |
| Emoji | 1 個（標題） | **2-4 個 ok** |
| 圖片 | 螢幕截圖 / 圖表 | **顏色鮮明的海報** |
| CTA | 評論 / 互動 | 標籤朋友 / 分享 |
| 連結策略 | 留言放連結 | **首條留言或圖片內 QR** |

**FB 演算法獎勵的指標**：reactions、shares、評論（按比例最重要）。圖片清晰 + 文字短 + 一個明確互動點 = 表現好。

## 海報設計系統

**品牌色**：
- 主色 翠綠 `#10b981`（emerald）
- 強調 琥珀 `#f59e0b`（amber）
- 警示 紅 `#dc2626`（red — major interaction）
- 背景 象牙 `#fefce8`（warm cream）
- 文字 石板 `#0f172a`（slate-900）

**字型**：Source Han Sans TC（思源黑體）+ Inter（英文）

**標準尺寸**（依用途）：
- FB 動態貼文方圖：1080×1080
- FB 動態貼文直圖：1080×1350（手機佔比更大）
- FB 封面：1640×856
- FB 限時動態 / Reels：1080×1920

**Logo + 浮水印**：每張海報右下角放小字 `evidencebasedtcm.com` + 小 EBTCM 字樣，確保被截圖轉發時仍有品牌歸屬。

## 海報模板（6 種重用）

存於 `poster-templates/`：

1. **01-hook-photo.svg** — 大標題 + 對比文字（起源故事、警示）
2. **02-quick-tip.svg** — 小提示 / 食療小貼士（每週至少 1 次）
3. **03-case-study.svg** — 「之前 / 之後」結構（案例分享）
4. **04-doctor-spotlight.svg** — 名醫頭像（用畫像或圖示）+ 一句金句
5. **05-data-stat.svg** — 大數字統計（25 條交互、707 證據等）
6. **06-cta-conversion.svg** — 行動呼籲（試用、訂閱、認證）

**使用流程**：
1. 在瀏覽器打開 SVG → 用編輯器（VS Code、Inkscape、Figma）改文字
2. 匯出 PNG（1080×1080）
3. 上傳到 FB

或直接在 Canva 重建 — 在每個 SVG 註解中提供 Canva 模板搜尋關鍵字。

## 快速回應 SOP

當有人留言 / 私訊：
- **2 小時內** 回覆（FB 演算法獎勵快速回應）
- **疑問 / 諮詢** → 引導到 `/interactions` 或私訊預約 demo
- **負面留言** → 公開禮貌回應 + 私訊深入溝通
- **病人具體醫療諮詢** → 公開回答「無法在 FB 上提供個別醫療建議，請諮詢您的中醫師。可看我們資料庫……」（公開化合規）
