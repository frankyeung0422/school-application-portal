# Week 3 — Image specs

## Image D · Monday post — Build-in-public update

**Format**: 1200×627

### If using Version A (first customer)

**Recommended**: a redacted Stripe receipt screenshot.

- Open the Stripe dashboard.
- Find the first paid charge.
- Redact (with a black rectangle in any image editor — Preview / Snipping Tool / Canva):
  - Customer name
  - Email
  - Last 4 of card
- Keep visible: the amount (HK$280), the product name ("EBTCM Professional — Monthly"), the date, the status badge (succeeded).
- Add a thin overlay caption: "First paying customer. Day 21 of build-in-public sprint."

**Alternative**: a screenshot of the Stripe dashboard's "Revenue this month: HK$280" widget. Clean, no PII.

### If using Version B (no close yet)

**Recommended**: a screenshot of your CRM/sheet showing the 3 maybes column.

- Spreadsheet with columns: practitioner | location | status | last-touch
- 3 rows visible, all status = "verbal yes, awaiting payment"
- Redact names to initials (or use placeholders)
- Crop tight, add caption: "Week 3. 3 maybes. 0 dollars. The trough."

**Alternative**: a Calendar screenshot showing this week's demo bookings → demonstrates pipeline activity even without revenue yet.

The honesty is the engagement engine. Don't try to dress up version B as a victory.

Colors per tier:
- Grade A: deep emerald `#047857`
- Grade B: emerald `#10b981`
- Grade C: amber `#f59e0b`
- Grade D: slate `#64748b`

**Add right side or bottom**: a small inset bar showing "Grade A density: TCM 20% vs. Cardiology 35% vs. Oncology 28%" — labelled "Field comparison (illustrative, not directly comparable)". This is the visual hook that says "context, not failure".

**Don't include**: the 5 Grade A examples on the image itself. Keep those in the post body so people read the post.

**Footer**: small EBTCM wordmark + URL on every image.
